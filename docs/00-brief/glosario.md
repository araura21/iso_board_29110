# Glosario

| Término | Significado en este proyecto |
|---|---|
| VSE | Entidad muy pequeña: empresa, departamento, proyecto u organización con un equipo de hasta 25 personas |
| Familia | Conjunto de normas relacionadas, por ejemplo ISO/IEC 29110 |
| Norma o parte | Documento individual de la familia, por ejemplo 29110-5-1-2 |
| Perfil | Subconjunto de ciclo de vida adaptado a un tipo de VSE: Entrada, Básico, Intermedio, Avanzado |
| Apartado | Sección de una norma que agrupa ítems, por ejemplo GP.1 |
| Ítem de verificación | Enunciado comprobable, por ejemplo GP.1.1 |
| Evaluación | Revisión de una norma para una organización en una fecha |
| Respuesta | Valor asignado a un ítem: C, P, NC o NA |
| C, P, NC, NA | Cumple, Cumple parcialmente, No cumple, No aplica |
| Evidencia | Archivo o enlace que respalda una respuesta |
| Brecha | Ítem marcado NC o P |
| GP | Proceso de Gestión del Proyecto |
| IS | Proceso de Implementación de Software |
| LT | Líder técnico |
| CL | Cliente |
| AN | Analista |
| DIS | Diseñador |
| PR | Programador |
| ET | Equipo de trabajo |
| RF / RNF | Requisito funcional / no funcional |
| ADR | Registro de decisión de arquitectura |

GP también abrevia al rol "gestor del proyecto" en las listas de verificación.
