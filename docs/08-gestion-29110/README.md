# Gestión del proyecto según el Perfil Básico

El equipo gestiona su proyecto aplicando el Perfil Básico (ciclo predictivo o ágil). Estos documentos forman el entregable 4 y la evidencia del criterio "Evidencias ISO/IEC 29110" (10 %).

| Producto de trabajo | Documento | Ítems que respalda |
|---|---|---|
| Enunciado del trabajo | [01](01-enunciado-del-trabajo.md) | GP.1.1 |
| Plan del proyecto | [02](02-plan-del-proyecto.md) | GP.1.2, IS.1.1 |
| Actas de reunión | [03](03-actas-de-reunion.md) | GP.2.1, IS.1.1 |
| Reportes de avance y acciones correctivas | [04](04-reportes-de-avance.md) | GP.2.1, GP.2.2, GP.3.1 |
| Solicitudes de cambio | [05](05-solicitudes-de-cambio.md) | GP.3.2 |
| Acta de aceptación | [06](06-acta-de-aceptacion.md) | GP.4.1 |
| Especificación de requisitos y validación | [Requisitos](../01-requisitos/funcionales.md) | IS.2.1 |
| Diseño y trazabilidad | [Arquitectura](../02-arquitectura/arquitectura.md), [matriz](../01-requisitos/trazabilidad.md) | IS.3.1 |
| Pruebas | [Plan e informe](../07-pruebas/plan-pruebas.md) | IS.4.1, IS.5.1 |
| Configuración de software y guías | Repositorio, manuales y [documento de mantenimiento](../09-entrega/documento-mantenimiento.md) | IS.6.1 |

Los registros se llenan cuando ocurren los hechos, con fechas reales. El historial de commits sirve de respaldo.
